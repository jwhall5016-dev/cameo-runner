$bookmark.create(bookmarkId, bookmarkObject)

Create a bookmark. The default element type for this function is "label".


NameTypeDescription
Parameter(s)bookmarkIdjava.lang.StringThe bookmark ID.
bookmarkObjectjava.lang.ObjectA bookmark object or content.
Return-com.nomagic.magicreport.BookmarkThe content with a bookmark.

For example:


$bookmark.create($element.elementID, $element.name)

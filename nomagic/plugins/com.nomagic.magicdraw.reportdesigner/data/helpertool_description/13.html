$bookmark.openURL(url, content)

Create a hyperlink to open a URL.


NameTypeDescription
Parameter(s)urljava.lang.StringA URL text.
contentjava.lang.ObjectThe text content.
Return-com.nomagic.magicreport.LinkThe text content with a hyperlink.

For example:


$bookmark.openURL("http://www.nomagicasia.com","NoMagic Asia")

Jar Dependencies
https://velocity.apache.org/engine/1.7/build.html#jar-dependencies


Velocity requires following libs at runtime:

    commons-collections-3
    commons-lang-2



For commons-lang, Report uses the lib from MagicDraw (org.apache.commons.lang-2.6.0.vxxxx.jar).
For commons-collections-3, MagicDraw does not contain commons-collection-3, it has only commons-collections4.
So, this lib has not yet been removed from report lib.
